## Agent skills

### Issue tracker

Issues y specs viven como markdown en `.scratch/<feature>/`. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Cinco roles canónicos, cada etiqueta igual a su nombre: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. Ver `docs/agents/triage-labels.md`.

### Domain docs

Single-context: un `GLOSSARY.md` y `docs/adr/` en la raíz. Ver `docs/agents/domain.md`.
